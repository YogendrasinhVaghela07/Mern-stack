# Laundry Service Hero Section

A simple web application page designed for a laundry service.

## Features

- Navigation bar with:
  - Logo
  - Home
  - Services
  - About Us
  - Contact Us
  - Username
- Hero section with two divisions:
  - Left side contains a heading, description, and **Book a Service Today** button.
  - Right side contains a laundry-related image.
- Used `float` and `display: inline` for layout.
- Flexbox is not used.
- Viewport units are used to help fit the section within the screen.

## Technologies Used

- HTML
- CSS
