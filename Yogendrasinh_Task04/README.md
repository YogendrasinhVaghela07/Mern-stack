# Task-04

A simple webpage created using HTML and CSS.

## Features

- Displays an image on the webpage.
- Uses viewport units (`vh` and `vw`) for responsive spacing.
- Image width is set to `100%`.
- Includes a gradient section below the image.
- Contains a clickable **"Click me"** link.
- The link redirects to a Wikipedia page about mountains.
- Text is centered using `text-align` and `line-height`.

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Used

- Margin using `vh` and `vw`
- `display: block`
- `width: 100%`
- Linear Gradient
- `text-align`
- `line-height`
- Text styling
- Removing link underline using `text-decoration: none`

## Project Structure

```text
Task-04/
│
├── index.html
├── style.css
└── image.jpg
```

## How It Works

The webpage displays an image with responsive spacing around it. Below the image, a colorful linear gradient section contains a clickable link. When the user clicks **"Click me"**, they are redirected to the Mountain page on Wikipedia.
