# 🧺 Laundry Wallah / Laundry Mart

A simple and responsive laundry service website created using **HTML**.

## 📌 Project Description

Laundry Wallah / Laundry Mart is a basic website designed to provide information about laundry services. Users can view the available services, pricing details, and submit their contact information for booking.

## ✨ Features

- Welcome section with introduction
- Laundry service image
- List of available services
- Service and pricing table
- Book Now form
- Contact information

## 🛠️ Technologies Used

- HTML5

## 📋 Services Offered

- Efficient Garment Sorting
- Stain and Damage Inspection
- Precise Washing and Drying
- Quality Ironing and Pressing
- Tagging and Inventory Management

## 💰 Pricing

The website displays pricing details for different services such as:

- Washing and Drying
- Ironing and Folding
- Formal Shirts / T-Shirts
- Trousers / Jeans

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open the `index.html` file.
4. Run the project using **Live Server** or open the HTML file directly in a web browser.
