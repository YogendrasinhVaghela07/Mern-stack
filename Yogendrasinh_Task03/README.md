# Basic CSS Practice

This project is a simple webpage created to practice the basic concepts of **CSS styling**.

## 📌 Project Description

This webpage demonstrates different ways of applying CSS styles to HTML elements using:

- Element selectors
- Class selectors
- ID selectors
- Styling headings
- Styling paragraphs
- Styling links
- Styling ordered and unordered lists
- Applying colors and backgrounds

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Concepts Practiced

- Using a class selector (`.head`)
- Using an ID selector (`#bglim`)
- Styling HTML heading elements
- Styling paragraph elements
- Styling anchor (`a`) tags
- Styling list items
- Applying text colors
- Applying background colors
