# Task-05: Responsive Landing Page

## Description
Created a simple landing page using HTML and CSS. The webpage contains a navigation bar and a hero section for a laundry service website.

## Features
- Navigation bar with logo, menu links and username.
- Hero section with heading, description and call-to-action button.
- Laundry service image.
- Responsive design using CSS Media Queries.
- Different styling for desktop, tablet and mobile screen sizes.

## Technologies Used
- HTML5
- CSS3
- CSS Float
- CSS Flexbox
- CSS Media Queries

## Learning Outcomes
- Learned to create layouts using HTML and CSS.
- Understood the use of Float and Flexbox.
- Practiced responsive web design.
- Learned how to use Media Queries for different screen sizes.

## Project Structure
- `index.html` – HTML structure
- `style.css` – CSS styling
- `logo.jpg` – Website logo
- `image.png` – Laundry service image
