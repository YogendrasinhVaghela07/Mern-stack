# Task – Hover and Transform Effects

## Description
Created a webpage using HTML and CSS. Implemented CSS `hover` and `transform` properties to add interactive effects to the existing page.

## Concepts Used
- CSS `:hover` pseudo-class
- CSS `transform` property
- `rotate()` function
- `scale()` function
- CSS `transition` property
- Float-based layout

## Output
When the user hovers over the button, it smoothly rotates and increases in size using CSS transform effects.
