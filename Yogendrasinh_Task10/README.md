# Task – CSS Animations

## Description
Added CSS animations to the existing webpage using `@keyframes` to create movement and scaling effects on the hero image.

## Concepts Used
- CSS `@keyframes`
- CSS `animation` property
- `translate()` and `translateY()`
- `scaleY()` and `scale()`
- Animation duration (`2s`)
- Infinite animation iteration

## Output
The hero image continuously moves in different directions and changes its scale using CSS animations.
