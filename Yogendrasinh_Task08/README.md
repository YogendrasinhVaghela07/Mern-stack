# Responsive Hamburger Menu Using HTML & CSS

## Description
Created a responsive navigation bar with a CSS-only hamburger menu using a semantic HTML button and the CSS `:focus` pseudo-class.

## Features
- Responsive navigation bar.
- Hamburger button appears at screen widths of 375px or less.
- Menu visibility controlled using the `:focus` pseudo-class.
- Menu slides in from the right side.
- Smooth transition animation.
- No JavaScript used.

## Technologies Used
- HTML5
- CSS3

## Key Concepts
- Media Queries (`max-width: 375px`)
- Semantic HTML `<button>` element
- CSS `:focus` pseudo-class
- CSS `transform: translateX()`
- CSS `transition`
- CSS `opacity`
- CSS `pointer-events`

## Learning Outcome
Learned how to create a responsive hamburger menu without JavaScript using a semantic button, CSS focus selector, and slide-in transition animation.
