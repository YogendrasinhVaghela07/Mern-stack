# Responsive Hamburger Menu

## Description
Created a responsive navigation bar with a hamburger menu for mobile screens using HTML and CSS only.

## Features
- Responsive navbar.
- Hamburger menu appears at screen widths of 375px or less.
- Menu opens and closes using an HTML checkbox.
- Uses CSS `:checked` pseudo-class.
- Smooth menu animation using CSS transitions.
- No JavaScript used.

## Technologies Used
- HTML5
- CSS3
- Media Queries
- CSS Transitions
- Checkbox and Label

## Key Concepts
- `@media (max-width: 375px)`
- `input[type="checkbox"]`
- `:checked` selector
- `max-height`
- `opacity`
- `transition`

## Learning Outcome
Learned how to create an interactive hamburger menu without JavaScript using HTML checkbox and CSS.
